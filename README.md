# MO-diagram-python
Created an MO diagram uisng python to add to a synthesis lab report

This was in March 2026 for a lab synthesising ICl to investigate the binding of ICl to a pyridine adduct. As a part of this lab we generated MO diagrams of the frontier orbitals of ICl to justify through which atom ICl will bind to pyridine. Rather than drawing this out in ChemDraw, or Powerpoint I wanted to try and code this as I had seen a lecturer code his own MO diagrams during a physical chemistry lecture, and thought "maybe I could do this".

The IR and UV spectra were also plotted using pylab.
